# Калькулятор грехов (Sin Calculator)

Учебное desktop-приложение, реализующее шуточный расчет «количества совершенных грехов» и определение категории грешности на основе анализа привычек пользователя и показателей прокрастинации. Программа предоставляет удобный графический интерфейс с диалоговым опросником и графическим отображением результатов. Проект разработан на языке C++ с использованием библиотеки компонентов Qt Widgets и строго следует архитектурному паттерну **MVC с активной моделью (Active Model)**.

## Возможности
* **Интерактивный опросник:** Ввод пользовательских метрик (год рождения, часы прокрастинации в день, ночные перекусы, отложенные будильники).
* **Запоминание состояния:** Автоматическое сохранение и восстановление последних введенных данных на главной форме при повторном вызове диалога.
* **Строгая валидация:** Проверка вводимых значений на типы данных, пустые поля и допустимые диапазоны с выводом модальных окон ошибок (`QMessageBox::critical`).
* **Реализация Active Model:** Автоматическое оповещение представления моделью через систему сигналов и слотов Qt (паттерн Observer) сразу после пересчета результатов.
* **Анализ и вердикт:** Расчет суммарного количества грехов по формуле и присвоение категории («Почти праведник», «Магистр лени», «Архидемон откладывания на потом»).

## Технологии и архитектура
* **Язык программирования:** C++ (стандарт C++17)
* **Графический интерфейс:** Qt Widgets (поддержка Qt5 / Qt6)
* **Система сборки:** CMake
* **Паттерн проектирования:** MVC с активной моделью (Active Model) + Observer (Qt Signals &amp; Slots)
* **Среда разработки:** VS Code / Qt Creator / CLion

## Сборка и запуск (Linux / GCC)

### Предварительные требования
Убедитесь, что в системе установлены компилятор C++, CMake и библиотеки Qt:
```bash
sudo apt update
sudo apt install -y build-essential cmake qtbase5-dev

```

### Компиляция

# Переход в директорию с проектом
cd SinCalculator

# Создание каталога сборки
mkdir build &amp;&amp; cd build

# Генерация файлов сборки и компиляция
cmake ..
cmake --build .

# Запуск приложения
./SinCalculator
